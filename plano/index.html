Configuracao de DNS

Apontar dominio para a VPS • Pre-requisito para tudo

No painel do registrador (Registro.br ou similar), criar/atualizar os registros A:

RegistroTipoValor
paipoeta.com.brA72.61.129.237
www.paipoeta.com.brA72.61.129.237

Verificacao

dig +short paipoeta.com.br A # Deve retornar: 72.61.129.237
Atencao: A propagacao DNS pode levar de 15 minutos a 48 horas. So prossiga para os proximos passos quando o dig retornar o IP correto.
2

Nginx Reverse Proxy

Proxy reverso para o Plone via dominio

Conectar na VPS e criar a configuracao do Nginx:

ssh -i ~/.ssh/id_ed25519_icevps root@72.61.129.237

Criar o arquivo de configuracao:

cat > /etc/nginx/sites-available/paipoeta.com.br << 'EOF' server { listen 80; server_name paipoeta.com.br www.paipoeta.com.br; client_max_body_size 20M; # Certbot challenge location /.well-known/acme-challenge/ { root /var/www/html; } # Redirecionar raiz para /portal/ location = / { return 301 /portal/; } # Proxy para Plone (VirtualHostBase rewriting) location / { proxy_pass http://127.0.0.1:8085/VirtualHostBase/http/paipoeta.com.br:80/portal/VirtualHostRoot/; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; proxy_read_timeout 120s; proxy_buffering on; proxy_cache_valid 200 10m; } } EOF

Ativar e testar:

ln -sf /etc/nginx/sites-available/paipoeta.com.br /etc/nginx/sites-enabled/ nginx -t && systemctl reload nginx

Verificacao (antes do DNS propagar)

curl -H "Host: paipoeta.com.br" http://127.0.0.1/ -s -o /dev/null -w '%{http_code}' # Deve retornar: 301 (redirect para /portal/) curl -H "Host: paipoeta.com.br" http://127.0.0.1/front-page -s -o /dev/null -w '%{http_code}' # Deve retornar: 200
Nota sobre VirtualHostBase: O Plone usa uma URL especial para rewriting interno. Isso faz com que o Plone gere URLs absolutas com o dominio correto (em vez de localhost:8085/portal/...).
3

SSL com Let's Encrypt

Certificado HTTPS gratuito e automatico
Pre-requisito: O DNS ja deve estar propagado antes de executar este passo.
certbot --nginx \ -d paipoeta.com.br \ -d www.paipoeta.com.br \ --non-interactive \ --agree-tos \ -m oguigodomingos@gmail.com

O Certbot vai automaticamente:

  1. Gerar o certificado SSL
  2. Modificar o config do Nginx para HTTPS
  3. Adicionar redirect HTTP → HTTPS

Apos SSL: Atualizar VirtualHostBase

No bloco server que o Certbot criou (porta 443), trocar o proxy_pass:

# Bloco 443 (criado pelo certbot) — atualizar proxy_pass: location / { proxy_pass http://127.0.0.1:8085/VirtualHostBase/https/paipoeta.com.br:443/portal/VirtualHostRoot/; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto https; proxy_read_timeout 120s; }
nginx -t && systemctl reload nginx

Verificacao

curl -s -o /dev/null -w '%{http_code}' https://paipoeta.com.br/ # Deve retornar: 200 # Verificar certificado echo | openssl s_client -servername paipoeta.com.br -connect paipoeta.com.br:443 2>/dev/null | openssl x509 -noout -dates
4

Seguranca — Fechar Porta 8085

Opcional mas recomendado • Apos confirmar que SSL funciona

Recriar o container para que a porta 8085 so aceite conexoes locais (loopback):

docker stop plone-paipoeta && docker rm plone-paipoeta docker run -d --name plone-paipoeta \ -p 127.0.0.1:8085:8080 \ -u root \ -v /opt/plone-paipoeta/data:/data \ plone-paipoeta:v4
Diferenca: 127.0.0.1:8085:8080 (so loopback) vs 0.0.0.0:8085:8080 (publico). Com loopback, so o Nginx local consegue acessar o Plone.

Configuracoes de SEO no Plone

Otimizacoes no painel admin do CMS

5.1 — Titulo e Descricao do Site

Acessar https://paipoeta.com.br/@@site-controlpanel:

CampoValor
Titulo do sitePai Poeta
DescricaoPortal do Pai Poeta — literatura, poesia, cultura e educacao para pais e filhos

5.2 — URL Base

Verificar em @@mail-controlpanel ou ZMI (/portal/manage_propertiesForm) que nao ha referencias a localhost:8085.

5.3 — Sitemap XML

Plone 4.3 gera sitemap automaticamente. Verificar:

curl https://paipoeta.com.br/sitemap.xml.gz -s -o /dev/null -w '%{http_code}' # Se 404: ativar em @@search-controlpanel → "Enable sitemap.xml.gz"

5.4 — robots.txt

Verificar que contem a referencia ao sitemap:

curl https://paipoeta.com.br/robots.txt # Deve conter: Sitemap: https://paipoeta.com.br/sitemap.xml.gz

Se nao tiver, adicionar no Nginx:

location = /robots.txt { return 200 "User-agent: *\nAllow: /\nSitemap: https://paipoeta.com.br/sitemap.xml.gz\n"; }

5.5 — Google Search Console

O site ja tem a tag de verificacao Google. Apos DNS + SSL:

  1. Acessar Google Search Console
  2. Adicionar propriedade https://paipoeta.com.br
  3. Submeter o sitemap: https://paipoeta.com.br/sitemap.xml.gz

5.6 — Redirect www → sem-www

Definir URL canonica (recomendado: sem www). No Nginx, bloco 443:

server { listen 443 ssl; server_name www.paipoeta.com.br; # ... certificados SSL ... return 301 https://paipoeta.com.br$request_uri; }
